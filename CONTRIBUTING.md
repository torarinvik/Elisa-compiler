# Contributing to Elisa

Anyone can contribute to Elisa. Bug reports, documentation, examples, tests,
and compiler changes are all welcome.

Contributions written in whole or in part by a large language model (LLM)
are welcome without restriction or disclosure requirements.

Open an issue to report a bug or propose an idea, or open a pull request to
share a change. The [development guide](docs/development/README.md) explains
how to build and test the compiler.
